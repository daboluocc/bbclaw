# Release v0.5.20 (2026-06-27)

## 发布方式
灰度发布（本地脚本 `release_local.sh`，直推 OTA，无 CI）。

## 命令
```bash
# 前置：备份 bench sdkconfig（脚本会覆盖成 bbclaw.latest），发后还原
cp firmware/sdkconfig /tmp/sdkconfig.bench.bak
export IDF_PATH=/Volumes/1TB/esp/esp-idf IDF_TOOLS_PATH=/Volumes/1TB/dev-tools/.espressif
source "$IDF_PATH/export.sh"
export OTA_ADMIN_KEY=$(ssh root@daboluo.cc "grep '^CLOUD_OTA_ADMIN_KEY=' /opt/bbclaw-cloud/config/cloud.env | cut -d= -f2-")
cd firmware && ./scripts/release_local.sh v0.5.20
cp /tmp/sdkconfig.bench.bak firmware/sdkconfig   # 还原 bench 配置
```
