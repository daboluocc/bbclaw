## A. 螺孔（4× M3，5mm 内缩）

孔位对称、内缩一致，**位置本身没问题**；问题在孔周器件侵入。
M3 钻孔半径 63mil（1.6mm），螺帽/垫圈 keep-out 半径 118mil（3mm）。

| 孔 | 坐标(mil) | 冲突 | 判定 |
|---|---|---|---|
| TL | (192, 2878) | **C14 焊盘距孔心仅 42.2mil** | ❌ 焊盘落在钻孔内，必炸 |
| TL | (192, 2878) | R9 本体距孔心 52.9mil / 焊盘 92.2mil | ❌ 本体压孔 |
| TL | (192, 2878) | C13 115mil、C15 109.5mil | ⚠️ 侵入垫圈区 |
| TR | (1383, 2878) | C12 102.5mil | ⚠️ 侵入垫圈区 |
| BR | (1383, 192) | D2（SMAJ5V0，SMB 大焊盘）64.7mil | ⚠️ 本体贴着钻孔边缘 |
| BL | (192, 192) | SH1 142.6mil | ✅ 通过 |

**结构性建议**：40mm 宽的手持件用 M3 偏重。换 **M2（Ø2.2mm 孔 / Ø4mm 柱）**
每角可回收约 1.5mm 半径，上表 ⚠️ 三条自动消失，只剩 C14/R9 需要挪。

## B. Type-C 方位（U8 20009-UCAF001-X）

| 项 | 实测 | 判定 |
|---|---|---|
| 所在边 | 底边 | ✅ 符合需求「USB-C 底边居中」 |
| X 居中 | 中心 x=790，板中心 787.5 → 偏 2.5mil | ✅ 可视为完美居中 |
| 出板 | 本体越出底边 **33mil（0.85mm）**，焊盘全在板内 | ⚠️ 见下 |
| D± 走向 | U8(790,301) → U10 ESD(447,119) → U9 CH340(750,1414) | ❌ 见下 |

1. **0.85mm 外凸不是标准姿势**——常规是插合面与板边齐平（或板边开豁口）。
   外凸意味着板框不再等于外壳开孔基准。除非外壳是照这个凸出量画的，建议上移 33mil 齐平。
2. **D± 绕了一个大回头弯**：U8 的 D± 焊盘在 x=760~820，而 ESD U10 却摆在
   x=410~484、y=74~164（**在连接器焊盘排的下方偏左**），D± 先向左下拐再折回右上去 CH340。
   这就是 lint 里 `USB_DM × USB_DP` 两处自交叉的来源。
   正解：U10 移到 Type-C **正上方**（x≈790，y≈450~550）串在 D± 直通路径上——
   既是 ESD 的正确位置（紧贴对外接口），又让 U8→U10→U9 走一条直线。
   **当前挡路的正是 H3/H4 麦克风排针**（y=530，x=653/1010）。
3. D± 从 U8(y=3.7mm) 到 U9(y=38.7mm) **35mm**，全速 12Mbps 能跑，但偏长。

## C. 外接端子 / 边缘件

当前边序（自下而上）：

| 边 | 器件（y, mm） |
|---|---|
| 左 | SH1 电池焊端 10.7（底层）→ LED1 充电灯 17.5 → **SW1 电源拨动 24.9** → H2 喇叭 7P 38.1 → **U5 PTT 触摸弹簧 49.4** → H1 调试 6P 60.7（底层） |
| 右 | D2 4.1 → **SW2 静音拨动 13.0** → SW3 RESET 21.6 → FPC1 屏 8P 33.1 → SW5 KEY2 45.7 → **U4 拨轮 64.3** |
| 底 | U8 Type-C（居中） |
| 板中（底层） | **H3 / H4 麦克风 2.54 排针 y=13.5，x=16.6 / 25.7** |

### C1. ❌ H3/H4 麦克风排针位置是本板最大的布局问题
- 信号 MICSD / LRC / BCLK 全部从 **U7 模组左边缘**（x=449，y=2468~2618）出来，
  却要跑到 y=13.5mm 的板底中央——**单程约 53mm**。
- 且 LRC/BCLK 与左边的 H2 喇叭座共用，形成 U7 →（左）H2 → （下）H4 的折线，
  142 条交叉里很大一块由此产生。
- 它同时**占住了 Type-C D± 的正上方逃逸通道**（见 B2）。
- → 移到 H2 附近（左侧中段 y≈30~45mm）可一举解决两件事。**但这是外壳/麦克风安装位决定，需拍板。**

### C2. ⚠️ H1 调试 6P 的路由税
v2 已经上了 CH340 + 自动下载，H1（VBUS/GND/TXD0/RXD0/IO0/EN）按 D4 决议保留做救砖。
但它摆在**左上 y=60.7mm**，而 CH340 在 y=38.7mm 中部——UART0 组因此有**两个终点**，
TXD0/RXD0/EN/IO0 被拉出两条长线。建议把 H1 挪到 U9 旁边，UART 组收成一簇。

### C3. ⚠️ SW3（RESET）在右侧拇指区中段
右列自下而上是 静音 13.0 / **RESET 21.6** / 屏 33.1 / KEY2 45.7 / 拨轮 64.3——
RESET 落在拇指自然扫掠范围内，误触风险高。RESET 属救援件，应下沉到底边、
做沉孔/针孔式，或至少退到远离拨轮的一端。

### C4. ℹ️ 三件执行器越出板框（正常，但要写进机构文档）
SW1 左出 1.7mm、SW2 右出 1.8mm、U4 拨轮右出 2.4mm、U5 左出 1.1mm
（**焊盘全在板内，lint off-board=0**）。拨动件/滚轮穿壳是设计意图，
但**外壳横向包络实际是 ~45mm 而不是 40.26mm**，需在机构文档标注，否则开壳必撞。

## D. 拨盘（U4 WS-003）位置

| 项 | 实测 |
|---|---|
| 中心 | (38.1, 64.3) mm — 右上角，紧邻 ESP32 模组 |
| 与 TR 螺孔 | 3.6mm，通过 |
| 与 U7 模组 | 间隙 4.1mm，通过 |
| 引脚 | GPIO1 @(1360,2569) / GPIO6 @(1360,2648) / GPIO8 @(1360,2412) |

1. **人机**：78mm 高的机器单手握持，拇指舒适弧大约在 y=20~50mm；
   拨轮在 **y=64mm（82% 高度）**，属于要伸到顶角去够。且它高于屏（FPC1 y=33mm）
   和 KEY2（y=45.7mm）——滚轮反而是右列最难够的那一个。
2. **❌ 引脚分配让它注定难布**：U4 三个信号里
   - GPIO1 在 U7 **右**边缘（1138, 2918）✅ 就近
   - **GPIO6 在 U7 左边缘（449, 2718）**、**GPIO8 也在左边缘（449, 2418）** ❌
   → 三分之二的拨轮信号要横穿整个模组（约 690mil）绕到右边。
   这是**原理图引脚分配问题**，不是摆放能救的。把 IO6/IO8 换成模组右边缘的空脚
   （与 IO1 同列）可直接消掉一批交叉——代价是**固件引脚表要同步改**（跨组件契约）。
3. 顶部还要给 WROOM-1U 的 **IPEX 天线馈线**留出线通道，右上角目前被
   拨轮 + TR 螺孔 + C12 挤满。

## E. 元器件布局（整体）

**score 0/100，142 交叉 vs 门限 8 — 当前状态在 2 层板上基本不可布通，必须重摆一轮。**

### E1. 去耦电容形同虚设（15 条 decap-too-far）
| 电容 | 距目标脚 | 目标 |
|---|---|---|
| C18 | **24.6mm** | U6 +3V3 |
| C17 | **20.7mm** | U6 +3V3 |
| C6 | 17.9mm | U64 +5V |
| C7 | 14.5mm | U64 +5V |
| C13 / C14 / C15 | 10.3 / 7.6 / 4.4mm | U7.2 +3V3 @(449,2918) |
| C1 / C2 / C4 | 5.2 / 5.6 / 5.7mm | VBUS / VBAT |
| 其余 6 条 | 2.8~3.4mm | 略超 2mm 线 |

规范线是 ≤2mm。C17/C18 离目标 20mm+ 已经不是"去耦"，只是两颗挂在网上的电容。

### E2. 功能块互相穿插，不是分区布局
- 电源链 SH1→SW1→U1→U2/L1/D1→U64 大体在左下→中部，但 +5V 输出电容 C6/C7
  被甩到 (27.9, 29) / (22.2, 29.5)。
- 音频组被劈成两半（H2 在左，H3/H4 在板底中央）。
- UART 组有两个终点（U9 中部、H1 左上）。
- **U9 CH340 的 TXD0/RXD0 焊盘在自己的左下（x=575/625, y=1414）**，
  而 U7 的 TXD0/RXD0 在模组**右**边缘（x=1138）——UART 对角穿板。
  U9 转 180° 或右移，可让 UART 走同一列。

### E3. 手焊间距（hand-solder profile，min-gap 40mil）
3 处 tight：`C2↔R1` 28mil、`C20↔R1` 38mil、`R1↔U9` 38mil。

### E4. 其它
- C2 位号侧向摆放（silk-flipped），规范 §11.2 要求正立。
- 0 个 Mark 点（241 个顶层焊盘）。JLC 拼板工艺边自带，本体可不加，但细间距件建议补局部 Mark。
- **TP1–TP4 测试点（VBUS/VBAT/+5V/+3V3）仍未放**（v1 需求第 12 条 / S1 遗留项 ①）。

## F. ❗ 超出布局范围但阻塞布局的缺件

**SW4 + C11（KEY1 = IO42）在原理图和 PCB 中都不存在。**

实测：`KEY1` 网只有 1 个成员 `U7`（模组右边缘 x=1138, y=2718），是条悬空网。
04-IO-HMI 页器件表只有 `SW5`，没有 `SW4`；`C12` 在、`C11` 不在。

对照 `bbclaw-v2-requirements.md` 第 7 条：**KEY1=IO42、KEY2=IO41 两颗按键**。
`bbclaw-v2-s0-proposal.md` 的过程记录写到 autoconnect 把 `SW4/C11`、`SW5/C12`
两组共线合并进 GND，"删树重连+挪件修复"——**SW5/C12 修回来了，SW4/C11 没有**。

→ 当前板子只有一颗功能键。补回 SW4 需要在右列再占一个位置，
**所以必须在定稿摆放之前解决**。

## 处理建议（按依赖排序）

**必须先拍板（机构/契约，agent 不能替你定）**
1. 麦克风端子 H3/H4 放哪（决定 USB 通道能否打通 + 音频组能否收拢）
2. 拨轮 Y 位置 + 是否接受 IO6/IO8 重映射到模组右列（动固件引脚表）
3. SW4/KEY1 是补回两键，还是正式砍成单键（需求要改）
4. 螺丝规格 M3 保留 vs 换 M2（决定角部要挪几个件）

**拍板后可直接执行（无歧义）**
5. C14/R9 移出 TL 钻孔；C12/D2 退出垫圈区
6. U10 ESD 移到 Type-C 正上方，D± 走直线；U8 上移 33mil 齐平板边（若外壳无凸出量要求）
7. C13/C14/C15 贴到 U7.2；C17/C18 贴到 U6；C6/C7 贴到 U64
8. U9 转向，让 UART 与 U7 右列同侧；H1 移到 U9 旁
9. 修 3 处 tight（R1/C2/C20/U9）+ C2 位号转正
10. 补 TP1–TP4 测试点
11. 重跑 `layout-lint --gate` 直到 score ≥60 / 交叉 ≤8，再确认 P2 分档、进 P6/P7

# 执行记录（2026-08-01，用户拍板后落地）

用户四项决策：① 麦克风端子移到左侧紧邻 H2；② 拨轮下移 + IO6/IO8 重映射到模组右列；
③ 补回 SW4+C11 两键；④ 螺丝换 M2。以下为实际执行与实测结果。

## 1. 原理图：补回 SW4 + C11（KEY1 = IO42）

- 04-IO-HMI 页新增 `SW4`（K2-1806SA-A3DW-04 / C2690015）@(370,320) rot270
  + `C11`（CC0603KRX7R9BB104 / C14663）@(430,320)。
- 拓扑照抄已验证的 SW3/SW5：**pin1 = 信号，pin2/3/4 = GND**（v1 实机验证过的接法）。
- 实测网：`KEY1 = {U7, SW4, C11}`、`KEY2 = {U7, SW5, C12}` — 对称。
- ⚠️ **固件现状**：`firmware/boards/bbclaw/board_config.h` 注释明写
  「KEY1/KEY2 (GPIO42/41) are unused」，OK/BACK 目前全靠拨轮 PUSH 长短按。
  硬件补回两键后，固件要不要用是独立决策。

## 2. 原理图：拨轮 3 线重映射

| 功能 | 原引脚 | 新引脚 | 模组焊盘 |
|---|---|---|---|
| WHEEL_UP（原 GPIO8） | IO8（模组**左**边缘 pad12） | **IO38** | pad31 @y2518 |
| WHEEL_PUSH（原 GPIO1） | IO1（右上 pad39） | **IO39** | pad32 @y2568 |
| WHEEL_DOWN（原 GPIO6） | IO6（模组**左**边缘 pad6） | **IO40** | pad33 @y2618 |

- 三脚在模组右列**相邻连号**，与拨轮焊盘自下而上顺序一一对应，零交叉。
- 网名由 `GPIO1/6/8` 改为功能名 `WHEEL_PUSH / WHEEL_UP / WHEEL_DOWN`。
- 旧 IO6/IO8/IO1 已置 no-connect；**pad28/29/30 = IO35/36/37 是 N8R8 的
  Octal PSRAM 占用脚，全程未碰**。
- U4 的 T/C 触点归属（requirements 遗留项 ③）**未动**——仍按引脚号接线，
  首件仍需物理确认。
- 验收：bridge-check 0 桥接 / 0 孤儿；`sch check` 电气项全 0
  （0 悬空脚 / 0 geom-net 失配 / 0 多网线 / 0 零长线）；`sch drc` 0 fatal / 0 error。
- ❗ **固件待改（不在本次范围）**：v2 引脚表与 v1 不同，**不能直接改
  `boards/bbclaw/board_config.h`——那份服务的是已出货的 v1 板**。v2 应新建板型配置：
  `BBCLAW_NAV_BTN_UP_GPIO 38` / `BBCLAW_NAV_BTN_OK_GPIO 39` / `BBCLAW_NAV_BTN_DOWN_GPIO 40`
  （`BBCLAW_BUTTON_TEST_GPIO` 同步改 39）。

## 3. 螺孔：M3 → M2，孔心不动

## 5. 仍未解决 / 需要决策的

1. **去耦仍有 15 条超 2mm**（最差 C13 10.5mm / C4 9.4mm / C14 8.6mm）。
   已用「从目标引脚向外螺旋搜索」重跑，**大部分找不到更近的合法空位**——
   根因是**板子面积已经吃满**：67 件里只有 5 件在底层。
   真正的解只有三条：**① 更多器件挪到底层**（当前只有 H1/H3/H4/SH1/M1）、
   **② 板子放大**、**③ 上 4 层**。这是要拍板的取舍，不是摆放技巧能救的。
2. **ratsnest 129 交叉 / layout-lint score 0**：`--gate` 的门限（score≥60、交叉≤8）
   是通用阈值，对 67 件双层手持板不现实（v1/v2 上一版是 867 track / 92 via 布通的）。
   **硬性项（short/overlap/off-board/tight/no-access）已全部清零**，可以进布线；
   但 129 交叉意味着**过孔会很多**，同样指向上面那三条路。
3. **丝印压焊盘还剩 13 条**，需要再跑一轮 `silk-align` 或手工挪。
4. **TP1–TP4 测试点仍未放**（requirements 遗留项 ①）。
5. **SW3 (RESET) 位置未动**（右边 21.6mm，在拇指扫掠区）。
   本次判断：不挪件，改为**外壳开针孔/沉孔**（需牙签/回形针才能按），
   既消除误触又不动布局。若你要物理挪位请说。
6. **外壳横向包络 ≈ 45mm，不是 40.26mm**——SW1 左出 1.7 / SW2 右出 1.8 /
   U4 拨轮右出 2.4 / U5 左出 1.1mm（焊盘全在板内，属执行器穿壳）。必须写进机构文档。
7. **FPC1（屏 8P）位置未动**。它卡在右边 33mm，正好占住拇指弧的黄金位，

## 6. ❌ 麦克风端子摆错了 —— 已回退到原始并排几何

**用户指出**：麦克风是「平行的那个」——模组**平行贴在板面上方**，跨接在两排排针上。

**我的错误**：第一轮把 H3/H4 当成两个独立的 3P 座，**竖着串排**放到左侧
（同一 x=330，y 相距 330mil）。这直接破坏了模组的插接几何——模组根本插不上。

**实测原始几何**（从改动前的快照复原）：

| | H4 | H3 |
|---|---|---|
| 中心 | (653, 530) | (1010, 530) |
| 旋转 | 270° | 90° |
| 焊盘 y | 630 / 530 / 430 | 630 / 530 / 430 |
| 网（上→下） | GND / LRC / BCLK | GND / +3V3 / MICSD |

→ 两列**平行竖排**，**行对齐**（y = 430/530/630，2.54mm 间距），
**列间距 357mil = 9.07mm**。这是一个 **2×3 = 6 脚双排**插座，
麦克风模组横跨两排、平行于 PCB。

**已回退**：H3/H4 恢复到**逐坐标一模一样**的 (653,530) / (1010,530)，
旋转 270°/90° 不变，两列间距 9.07mm 不变。
⚠️ **9.07mm 这个列间距请对着实物再核一次**——它不是标准整数值，
是从原设计复原出来的，我没有实物可比对。

**连带处理**：U10（USB ESD）第一轮被我放到 Type-C 正上方，正好落在两排麦克风座中间。
两排之间的通道净宽 249mil，U10 宽 144mil，**放得下**——已挪到 (818,530)，
两侧间隙 40.5mil / 67.5mil，既守住 D± 直通路径，又不占排针位。
（D± 本来也必须从这个通道穿过去。）
⚠️ 若麦克风模组是**紧贴板面**安装而不是靠排针架高，U10 在模组正下方可能顶到，
**需要你按实物确认**；顶到的话把 U10 挪出去、D± 绕行即可。

**让位的件**：R21 / R22 / C1 / R4（USB CC 下拉 + VBUS）已重新落位到连接器右侧
（距目标脚 6.6~8.4mm）。CC 是直流电平，距离无碍；C1 作为 VBUS 储能电容偏远，计入下方遗留项。

**代价**：麦克风回到板底后，MICSD/LRC/BCLK 的长线回来了 ——
ratsnest 交叉 129 → **141**，走线 40411 → 43800mil。这是机构约束换来的，无法两全。
