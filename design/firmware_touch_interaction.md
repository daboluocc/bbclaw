# 固件触摸交互统一语义(触摸板通用)

状态: 已实施(手表 waveshare-amoled-206 + 实战派 lichuang-szp)
日期: 2026-07-19
实现: `src/bb_touch_input.c`(屏幕级手势/空白点按)+ 各 UI 模块(控件点按)

## 原则

所有带触摸的板共享**同一份交互语义**,不允许板级各自发明。触摸是 LVGL 原生
指针 indev(跟手滚动/点按/拖动),手势与空白点按是屏幕级统一层。物理按键
(BOOT=PTT)与 devmon 注入通路不受触摸影响。

## 统一语义表

| 手势 | 语义 | 说明 |
|------|------|------|
| **右滑** | BACK(返回/上一级) | 设置内逐级退出;聊天页 AI 回复中 = **取消当前回合**(有副作用,慎用) |
| **左滑** | 聊天页 = **打开设置** | 回复中也可进,不打断 TTS(与 OK 同语义、无取消副作用);其余页 = 页面自定义 LEFT(回放页=上一首) |
| **点击控件** | 控件原生操作 | 设置行选中+执行、回放传输键、音量条拖点、PTT 屏上钮等 |
| **空白单点** | BACK(退出/上一级) | **仅设置态(BB_PAGE_SETTINGS,含其子页/回放页)生效**;点在无任何可点控件的区域 = 与右滑 BACK 等价 |
| 任意触摸按下 | 用户活动上报 | 息屏计时复位/亮屏(ADR-046) |

## 空白单点=退出 的边界(为什么聊天页不生效)

- 聊天页(BB_PAGE_CHAT)是主页,无处可退;且 busy 时 BACK 语义是取消回合,
  误触空白导致打断回答是不可接受的。
- LOCKED 页同理忽略。
- 判定"空白" = LVGL 点击事件的 target 是屏幕本身(没有命中任何可点控件)。

## 板级差异(允许项)

仅允许**页面布局/控件形态**差异(手表竖屏 410x502 vs 实战派横屏 320x240),
交互语义不允许分叉。历史教训:左滑进设置曾被 `#if BB_UI_PORTRAIT` 门控成
手表专属,实战派上无法进设置——修正为"竖屏或 BBCLAW_TOUCH_FT5X06_ENABLE
板均启用"(bb_radio_app.c)。新增触摸板时不需要写任何交互代码,开
`BBCLAW_TOUCH_FT5X06_ENABLE` 即得全套语义。
