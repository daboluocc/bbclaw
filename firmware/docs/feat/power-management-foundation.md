# 电池与功耗管理基础层（P0）

## 现状

- 当前固件没有独立的电压/电量采样模块。
- 显示层没有电量状态入口。
- 下一版将加入电池、电量显示、低电量提示与后续功耗策略，因此需要先建立基础层。

## 本阶段目标

- 固定面包板默认电量采样脚为 `GPIO3`（`ADC1_CH2`）。
- 新增 `bb_power` 模块，负责：
  - ADC 初始化
  - 电池电压采样
  - 电量百分比换算
  - 向 UI 暴露统一状态
- 在 LVGL 状态栏增加电量显示入口。
- 更新 `pin_map.md`，明确 `GPIO3` 接线与分压网络。

## 当前电路基线

- 电池采样默认采用分压到 ADC 的方式。
- 默认阻值：
  - 上拉电阻 `100k`
  - 下拉电阻 `100k`
  - ADC 节点并 `100nF` 到地
- 该配置用于单节锂电池：
  - `4.2V -> 2.1V`
  - `3.3V -> 1.65V`

## 软件基线

- 空电默认 `3300mV`
- 满电默认 `4200mV`
- 第一版百分比采用线性映射，后续可替换为电池曲线表。
- 第一版仅做显示与低电量判定，不在本阶段引入：
  - 充电状态检测
  - 自动关机
  - 动态降频/休眠
  - 电源路径切换

## P0 电量精度优化（2026-05，替代第一版线性映射）

第一版的线性映射（`(mv-3300)*100/(4200-3300)`）在实测中明显不准，原因与改进如下。

### 问题根因

1. **线性映射不符合锂电放电曲线**：单节锂电池电压在 3.7V 附近停留很久（约对应 40%~80% 电量），低电量区才快速跌落。线性映射导致满电掉电飞快、中段卡住、末端突然归零。
2. **空电压 3300mV 偏低**：带载压降下 3.3V 实际仍有约 10~20% 电量，进一步压扁低电量段。
3. **负载压降无补偿**：PTT 发射 / 功放 / WiFi 突发电流瞬间拉低电压 100~300mV，采样恰逢其时会"跳水"。
4. **跨采样周期无滤波**：现仅在单周期内平均 8 次 ADC，周期之间电压噪声 + 负载波动让百分比来回抖。
5. **ADC 前端**：100k/100k 高阻分压 + 100nF 采样电容，oneshot 首读易偏低。

### P0 改进（纯软件，不改硬件）

1. **OCV–SoC 曲线查表 + 线性插值** 替代线性映射。采用单节锂电池典型放电曲线（电压→电量），表外端点 clamp 到 0/100。`BBCLAW_POWER_BATTERY_FULL_MV` / `EMPTY_MV` 退化为 clamp 边界，曲线表为换算真相来源。
2. **EMA 指数滑动平均** 对换算前的电池电压做跨周期低通滤波，吸收负载瞬态与噪声。系数 `BBCLAW_POWER_EMA_ALPHA_PCT`（默认 25%，即新值权重 0.25）。首次采样直接置入，避免冷启动爬升。
3. **百分比迟滞**：仅当滤波后百分比相对上次显示值变化 ≥ `BBCLAW_POWER_HYSTERESIS_PCT`（默认 2%）时才更新显示值，消除 ±1% 抖动。
4. **ADC dummy read**：每次刷新先丢弃 1 次读数，再做 8 次平均，规避采样保持电容充电不足导致的首读偏低。

## 后续扩展

- 增加充电检测脚 / PMIC 状态输入（充电态需禁用迟滞的"只降不升"假设，并区分虚高满电）
- 增加 USB 供电与电池供电区分
- 增加低电量告警、自动省电策略与休眠唤醒策略
- 负载感知采样（P1）：PTT / 发射期间不更新电量，避免压降跳水
- 引入硬件电量计芯片做库仑计积分，根治 OCV 估算误差
